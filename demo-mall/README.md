# DEMO MALL × CodiPOP

영세몰 제휴 설득용 **웹 데모**입니다.

흐름: 몰 상품 상세 → **착용해 보기** → 내 사진 피팅 → 결과 → **이 상품 구매하기**(몰 복귀)

## 실행

### 로컬 (본인 PC만)

```bash
yarn demo-mall
```

`http://localhost:5173`

### 외부 공유 (다른 사람에게 보여줄 때)

Render 백엔드에 배포된 주소:

**https://codipop-backend.onrender.com/demo/**

이 링크를 카톡/메일로 보내면 됩니다.

## 데모 시나리오 (몰 사장님 앞에서)

1. 홈에서 상품 카드 선택
2. 상세 이미지 위 **착용해 보기** 탭
3. **체험용 사진 쓰기** 또는 본인 사진 선택
4. **AI 피팅 시작** (백엔드 `codipop-backend.onrender.com/try-on` 호출, 약 3~10초)
5. Before / After 확인 후 **이 상품 구매하기**

## 파일

| 파일 | 역할 |
|---|---|
| `index.html` | 화면 골격 |
| `styles.css` | 몰 상세 + 위젯 스타일 |
| `app.js` | 라우팅·피팅 API 연동 |
| `assets/` | 샘플 상품/인물 이미지 |

## 제휴 몰용으로 바꿀 때

`app.js`의 `PRODUCTS`에서:

- `image` → 실제 상품 이미지 경로/URL
- `buyUrl` → 실제 상품 상세 또는 장바구니 URL (`https://...`)

`buyUrl`이 있으면 **이 상품 구매하기**가 그 주소로 이동합니다.

## 참고

- 로그인/광고/옷장 없음 (파일럿 데모 범위)
- Render 무료 플랜이면 첫 요청이 느릴 수 있음 (콜드 스타트)
- 로컬 `file://`로 열면 모듈/경로 이슈가 날 수 있으니 **반드시 로컬 서버**로 실행
