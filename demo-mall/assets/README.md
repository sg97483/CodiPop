## `sample-person.jpg` 를 고를 때의 기준

**화면의 `체험용 사진` 버튼이 쓰는 이미지입니다.** 잘못 고르면 제품이 망가집니다.

전에 들어 있던 사진은 **얼굴 위주 상반신(헤드샷)** 이었습니다. 하의를 입히면
**목 아래에 바지가 그대로 붙은 결과**가 나왔습니다. 게다가 남성 사진인데
파일럿 후보 몰(리린·저스트원)은 둘 다 여성복 몰이었습니다.

교체 시 조건:

- [ ] **머리부터 발끝까지** 나온 전신 (가장 중요 — 하의 피팅이 여기서 갈립니다)
- [ ] 정면, 곧게 선 자세 (역동적인 포즈는 합성 품질이 떨어집니다)
- [ ] 단색·스튜디오 배경
- [ ] **프린트 없는 단순한 상하의** (AI 가 갈아입힐 바탕이 깨끗해야 합니다)
- [ ] 시연 대상 몰의 고객층과 크게 어긋나지 않을 것
- [ ] 상업적 사용이 허용된 라이선스

**고른 뒤에는 실제로 피팅을 한 번 돌려서 결과를 눈으로 확인하세요.**
이번 교체도 후보 2장을 실제로 합성해 비교하고 정했습니다.

## 남은 위험 — 초상권

Pexels 라이선스는 **사진의 저작권**을 풀어주지만 **사진 속 인물의 초상권**은 별개입니다.
라이선스 본문도 모델 릴리스에 대해서는 언급이 없고, "인물이 부정적으로 비치거나
허위로 보증하는 것처럼 보이면 안 된다"고만 정합니다.

우리 용도는 제품 안의 **기능적 샘플**(체험용 사진)이라 광고 모델과는 다르지만,
경계가 완전히 안전하지는 않습니다.

- ⛔ **이 사진을 광고·홍보물·랜딩페이지의 모델 이미지로 쓰지 마세요.** 허위 보증으로 읽힐 수 있습니다
- ✅ 파일럿이 확대되기 전에 **모델 릴리스가 있는 유료 스톡**이나 **직접 촬영**,
      또는 **AI 생성 인물**(실존 인물의 초상권이 아예 없음)로 교체하는 것이 안전합니다
