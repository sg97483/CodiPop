## 1. 데모용 화면 흐름

### 한 줄 스토리

> 고객이 몰 상세에서 옷을 보다가 → **착용해 보기** → 내 사진으로 피팅 → 결과 보고 → **구매하기**로 몰로 복귀

### 플로우 다이어그램

```
[몰 상품 상세]
   │  착용해 보기 탭
   ▼
[코디팝 피팅 웹 / 데모]
   │  내 사진 선택 (또는 저장된 모델 사진)
   │  (선택) 키/몸무게 — 파일럿 이후
   ▼
[피팅 중 로딩 3~10초]
   ▼
[피팅 결과]
   ├─ 다시 피팅
   ├─ 결과 저장/공유 (옵션)
   └─ 이 상품 구매하기 ──► [몰 상품 상세 / 장바구니]
```

### 화면별 구성 (데모 MVP)

| Step | 화면 | 보여줘야 할 것 | 몰 사장님에게 강조할 포인트 |
|---|---|---|---|
| 0 | **몰 상품 상세 (가짜/샘플)** | 상품 이미지, 가격, **착용해 보기** 버튼 | “우리 상세에 버튼만 붙으면 됩니다” |
| 1 | **피팅 시작** | 내 사진 업로드/선택, 상품 썸네일 고정 | 고객이 앱을 새로 깔 필요 없음 |
| 2 | **로딩** | 진행 표시 + “AI가 입어보는 중” | 3~10초 체감 (현재 엔진 ~6초대) |
| 3 | **결과** | Before/결과(가능하면), CTA 2개 | 구매 직전 확신 ↑ |
| 4 | **구매 복귀** | 원 상품 URL로 복귀 (또는 장바구니) | 트래픽·결제는 몰에 남음 |

### CTA 카피 (데모에 그대로 써도 됨)

- 버튼: `착용해 보기`
- 결과 1차 CTA: `이 상품 구매하기`
- 결과 2차 CTA: `다른 사진으로 다시 피팅`
- (옵션) `비슷한 코디 더 보기` — 파일럿 이후

### 데모에 넣을 샘플 데이터 (권장)

- 상품 2~3개만 (상의 1, 하의 1, 아우터 1)
- 모델 사진 샘플 1장 (고객이 사진 없을 때 “체험용”으로)
- 구매 버튼은 **실제 파일럿 몰 URL** 또는 데모용 더미 상세로 연결

### 기술적으로 데모가 증명해야 할 것

1. 상세 → 피팅 → 구매 복귀가 **끊기지 않음**
2. 상품 이미지(누끼/캡처)만 있으면 피팅 가능
3. 몰 쪽 작업은 **버튼/스크립트 수준**으로 보임 (개발 부담 최소)

### 데모에서 일부러 빼도 되는 것 (파일럿 전)

- 로그인 강제, 광고, 옷장/코디북 전체
- 카페24 정식 앱스토어 설치 플로우
- MD 대시보드 (대신 “피팅 N회” 숫자만 카톡/시트로 공유)

## 2. 파일럿 몰용 1페이지 제휴 제안서 뼈대

아래를 그대로 복사해 노션/한글/PPT 1장으로 쓰면 됩니다.

---

### 제목

**코디팝 × [몰명] — AI 착용해보기 파일럿 제안**

### 한 줄 제안

상품 상세에 **「착용해 보기」** 버튼을 붙여, 고객이 **앱 설치 없이** 내 사진으로 옷을 입어본 뒤 구매로 이어지게 합니다.

### 왜 필요한가 (몰 관점 3줄)

- 고객은 “예쁜데 나한테 어울릴까?”에서 이탈합니다.
- 영세몰은 모델 촬영·누끼·피팅룸 비용이 부담입니다.
- 코디팝은 **기존 상품 이미지**로 가상 피팅을 붙여, 상세 체류·구매 확신을 올리는 도구입니다.

### 파일럿으로 하는 일 (범위)

| 항목 | 내용 |
|---|---|
| 대상 | 인기/신상 상품 **10~20 SKU** |
| 노출 | 해당 상품 상세에 `착용해 보기` |
| 고객 경험 | 사진 업로드 → AI 피팅 → **구매하기(몰로 복귀)** |
| 몰 작업 | 버튼/스크립트 삽입 또는 코디팝이 대행 (합의) |
| 기간 | **2~4주** |
| 비용 | 파일럿 **무료 또는 실비(AI 호출)** — 협의 |

### 몰이 얻는 것

- 상세페이지에서 바로 피팅 → **이탈 감소 / 구매 결정 보조**
- 별도 앱 유도 없이 **웹에서 완결**
- 파일럿 종료 시 리포트: 피팅 횟수, 피팅 후 구매 클릭 수(측정 가능한 범위)

### 코디팝이 하는 것

- 피팅 엔진·버튼(위젯) 제공
- 상품 이미지 등록/검수 (URL 또는 이미지 전달)
- 파일럿 기간 기술 지원·간단 성과 공유

### 성공 기준 (미리 합의)

예: 2~4주 동안

- 피팅 시작 **N회** 이상
- 피팅 후 「구매하기」 클릭률 **X%**
- (가능하면) 피팅 유저 vs 비피팅 유저 전환 비교

※ 숫자는 몰 트래픽에 맞게 첫 미팅에서 채움.

### 이후 확장 (파일럿 성공 시)

1. 전 상품 / 카테고리 확대  
2. 월 이용료 또는 피팅당·클릭당 과금  
3. (선택) 카페24 등 호스팅 원클릭 설치  
4. (선택) 피팅 조합·미구매 신호 리포트

### 다음 액션 (CTA)

- [ ] 파일럿 상품 10개 리스트 공유  
- [ ] 상세 1개에 데모 버튼 붙여 내부 확인  
- [ ] 2~4주 파일럿 일정·담당자 확정  

**연락:** [이름 / 이메일 / 카톡]
